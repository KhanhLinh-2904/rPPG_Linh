## Program about rPPG detection and alert heart disease for elders
This project is for Final-term of course "Geriatric Health Promotion and Intelligent Medicine". The aim is to detect PPG signal, heart rate and heart disease, especially for elders. 

This project contains:
- Deep learning model: A two-stream model for PPG detection
- Algorithm to clacluate heart rate and alert heart disease
- Standalone program for using

### Download paper 
The link to download paper about two-stream model
``` bash 
https://ieeexplore.ieee.org/document/10735090
```
### 📦 Requirements

- Python 3.8+
- PyTorch
- scikit-learn
- matplotlib
- numpy

### Install dependencies:

```bash
pip install -r requirements.txt
```
